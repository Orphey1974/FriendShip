# FriendShip Frontend

Отдельное фронтенд приложение на Vite для демонстрации кросс-доменных запросов к API.

## Описание

Это приложение демонстрирует:
- Развёртывание фронтенда на отдельном хосте (Vite dev server)
- Кросс-доменные запросы к API приложению
- Отображение данных о погоде с красивом UI

## Технологии

- **Vite** - сборщик и dev server
- **React 18** - UI библиотека
- **CSS3** - стилизация с градиентами и анимациями

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите dev server:
   ```bash
   npm run dev
   ```

3. Откройте браузер по адресу: `http://localhost:5173`

## Требования

Для корректной работы приложения необходимо запустить API проект на порту 7099 (HTTPS) или 5176 (HTTP).
